# Java 101 — TP1

Welcome to the project site for the Java 101 TP1 examples.

This site gathers:

- Project metadata and reports generated by Maven
- Javadoc API for the sample classes
- Test reports and code coverage (JaCoCo)
- Dependency reports and trees

Use the navigation menu to explore the generated artifacts. The site is intended as a teaching aid; instructors can point students to the reports here when grading or explaining test results, coverage, or dependencies.
